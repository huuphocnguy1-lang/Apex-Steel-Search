# Glossary – ESP, hot rolling, casting, hydraulics abbreviations (Apex built-in expert note)

Topic: abbreviations, glossary, acronyms, terms.

| Abbrev. | Meaning |
|---|---|
| ESP | Endless Strip Production (Arvedi / Primetals) |
| CCM | Continuous casting machine |
| SEN | Submerged entry nozzle |
| EMBr / EMS | Electromagnetic brake / stirring |
| HRM | High Reduction Mill (roughing stands R1–R4); RM = roughing mill |
| ENT | HRM entry |
| SHP / PS | Pendulum shear (pendular shear) |
| PIL / PPM | Piler / plate piling mode |
| SHR / CRS | Rotary (crop) shear |
| EDH | Edge heater |
| IDH / IH | Induction heater |
| DSC | Descaler |
| FM / HSM | Finishing mill / hot strip mill (F1–F5) |
| HGC | Hydraulic gap control |
| AGC | Automatic gauge control |
| ASC | Automatic shape control |
| MTC | Mass-flow / tension control (likely, plant naming) |
| ITC | Interstand tension control (HRM) |
| HLC | Hydraulic looper control |
| WRB / WRS | Work-roll bending / work-roll shifting |
| WR / BUR | Work roll / back-up roll |
| RCH | Roll change |
| SG / SGC | Side guide / side guide control |
| PR / PRC | Pinch roll / profile control (PRC also pinch-roll control on some screens) |
| THC | Thickness control |
| MZC | Multi-zone (work-roll) cooling for flatness |
| FDT | Finishing delivery temperature |
| CT | Coiling temperature |
| LCS / ROT | Laminar cooling system / run-out table |
| HSS | High-speed (flying) shear |
| DC / DC1–3 | Down coiler(s) |
| WR1–WR4 (coiler) | Wrapper rolls |
| MAB | Mandrel (bearing / expansion status on coiler screens, likely) |
| LAS | Laser speed meter |
| CL dev | Centre-line deviation |
| C25 / C40 | Crown / wedge measured 25 / 40 mm from the strip edge |
| HYP | Yield-related strength value of the grade (N/mm², plant naming) |
| MES / L2 | Manufacturing execution system / Level-2 process automation |
| CSM | Central switching & monitoring (MCC, drives) |
| MCC | Motor control centre |
| VVVF | Variable voltage variable frequency drive |
| SLM | Smart line module (drive infeed) |
| PN / DP | Profinet / Profibus DP |
| AH / WH | Alarm high / warning high (group alarm flags) |
| LOTO | Lock-out / tag-out |
| PS / RS (hydraulics) | Piston side / rod side pressure |
| ISO 4406 | Oil cleanliness code (particles ≥ 4 / 6 / 14 µm) |
| HPU | Hydraulic power unit |
| HLP 46 / 68 | Mineral hydraulic oil viscosity grades |
